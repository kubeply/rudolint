# RDL3048 valid-label-key

- Default severity: style
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because label key names are part
  of the image metadata contract.

Requires Docker label keys to use the allowed lower-case key format. Keys must
start with `a-z`, end with `a-z` or `0-9`, contain only `a-z`, `0-9`, `.`, `-`,
`_`, or `/`, avoid reserved Docker namespaces, and avoid consecutive `..` or
`--` separators.

Bad:

```Dockerfile
LABEL Com.Example.Name="app"
```

Good:

```Dockerfile
LABEL com.example.name="app"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
