# RDK1005 ssh-mount-command-scope

- Default severity: warning
- Category: buildkit
- Provenance: Rudolint BuildKit-native rule.
- Autofix: no safe automatic fix is declared because the correct split depends on build step intent.

Detects `RUN --mount=type=ssh` steps where the SSH agent socket is available to
multiple command scopes. Opaque shell wrappers such as `sh -c` and `bash -lc`
also count as broad scope because the wrapper controls the inner command
environment. Keep the SSH mount on the single command that needs it instead of
combining setup, fetch, and build commands or hiding the command behind a shell
wrapper in the same `RUN`.

Bad:

```Dockerfile
RUN --mount=type=ssh apk add git && git clone git@github.com:example/private.git /src
RUN --mount=type=ssh sh -c 'git clone git@github.com:example/private.git /src'
```

Good:

```Dockerfile
RUN apk add git
RUN --mount=type=ssh git clone git@github.com:example/private.git /src
```

```yaml
severity:

```
