# RDL3029 no-from-platform-flag

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because platform selection is a build policy decision.

Avoids hard-coding `--platform` on `FROM` instructions. Prefer selecting the
platform at build time.

Bad:

```Dockerfile
FROM --platform=linux/amd64 alpine:3.20
```

Good:

```Dockerfile
FROM alpine:3.20
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
