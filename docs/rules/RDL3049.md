# RDL3049 missing-required-labels

- Default severity: info
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because label values are project
  metadata.

Requires labels declared in `.rudolint.yaml` `label-schema` to be present in
each final image stage. Intermediate stages referenced by `COPY --from` are
ignored.

Example config:

```yaml
label-schema:
  org.opencontainers.image.title: text
  org.opencontainers.image.source: url
```

Bad:

```Dockerfile
FROM alpine:3.20
LABEL org.opencontainers.image.title="rudolint"
```

Good:

```Dockerfile
FROM alpine:3.20
LABEL org.opencontainers.image.title="rudolint"
LABEL org.opencontainers.image.source="https://github.com/kubeply/rudolint"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
