# DL3009 clean-apt-lists

- Default severity: info
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because cleanup should be composed with the package-manager command.

Requires `apt-get update` or `apt-get install` layers to remove
`/var/lib/apt/lists/*` so package index data is not left in the image layer.

Bad:

```Dockerfile
RUN apt-get update && apt-get install -y curl
```

Good:

```Dockerfile
RUN apt-get update \
    && apt-get install -y curl \
    && rm -rf /var/lib/apt/lists/*
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
