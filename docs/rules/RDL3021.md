# RDL3021 copy-multiple-destination-slash

- Default severity: error
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because a trailing slash changes whether Docker treats the destination as a directory path.

Requires `COPY` instructions with multiple sources to use a destination ending
in `/`.

Bad:

```Dockerfile
COPY package.json yarn.lock /app
```

Good:

```Dockerfile
COPY package.json yarn.lock /app/
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
