# DL3020 prefer-copy

- Default severity: error
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct edit depends on project intent.

Prefers `COPY` for plain local files where `ADD` archive extraction or remote
fetch behavior is not needed.

This applies the same way in Linux and Windows Dockerfiles. A local file such
as `ADD vcpkg/vcpkg.json .` should generally be `COPY vcpkg/vcpkg.json .`
unless the Dockerfile intentionally relies on `ADD` behavior for a remote URL or
local tar archive extraction.

Bad:

```Dockerfile
ADD app.py /app/
```

Good:

```Dockerfile
COPY app.py /app/
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
