# SC2002 avoid-useless-cat

- Default severity: warning
- Category: shell
- Provenance: ShellCheck-compatible shell rule.
- Autofix: no safe automatic fix is declared because the receiving command's
  file-reading syntax depends on the command.

Detects `cat` commands with plain file operands that pipe into another command.
Prefer passing files directly to the command that consumes them when that
command supports file operands.

Bad:

```Dockerfile
RUN cat app.log | grep error
```

Good:

```Dockerfile
RUN grep error app.log
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
