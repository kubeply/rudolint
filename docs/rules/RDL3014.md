# RDL3014 apt-get-install-assume-yes

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because install option placement should be reviewed with the package command.

Requires `apt-get install` commands to use `-y`, `--yes`, or `--assume-yes` so
Docker builds do not block on interactive prompts.

Bad:

```Dockerfile
RUN apt-get install curl
```

Good:

```Dockerfile
RUN apt-get install -y curl
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
