# RDL3060 yarn-cache-clean

- Default severity: info
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because adding shell commands can
  change cache behavior and failure handling.

Requires `yarn cache clean` to run after `yarn install` in the same `RUN`
instruction unless the step uses a BuildKit `cache` or `tmpfs` mount targeting
`.cache/yarn`.

Bad:

```Dockerfile
RUN yarn install
```

Good:

```Dockerfile
RUN yarn install && yarn cache clean
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
