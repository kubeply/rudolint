# RDK1001 secret-like-arg-or-env

- Default severity: warning
- Category: buildkit
- Provenance: Rudolint BuildKit-native rule.
- Autofix: none yet.

Flags secret-like `ARG` or `ENV` names because image metadata and build logs can
expose them.

Bad:

```Dockerfile
ARG AWS_SECRET_ACCESS_KEY
```

Good:

```Dockerfile
RUN --mount=type=secret,id=aws install-tool
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
