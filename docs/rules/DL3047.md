# DL3047 wget-progress

- Default severity: info
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the desired wget
  verbosity depends on build logging needs.

Requires `wget` downloads to control progress output with `--progress`,
`-q`/`--quiet`, `-nv`/`--no-verbose`, or wget log-output flags.

Bad:

```Dockerfile
RUN wget https://example.com/archive.tar.gz
```

Good:

```Dockerfile
RUN wget --progress=dot:giga https://example.com/archive.tar.gz
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
