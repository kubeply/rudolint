# RDK1003 cache-mount-for-package-install

- Default severity: info
- Category: buildkit
- Provenance: Rudolint BuildKit-native rule.
- Autofix: no safe automatic fix is declared because the correct edit depends on project intent.

Suggests BuildKit cache mounts for package manager install steps to improve
repeat build speed.

`apk add --no-cache` is excluded because that command intentionally disables
apk's package cache.

Bad:

```Dockerfile
RUN apt-get update && apt-get install -y curl
```

Good:

```Dockerfile
RUN --mount=type=cache,target=/var/cache/apt apt-get update && apt-get install -y curl
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
