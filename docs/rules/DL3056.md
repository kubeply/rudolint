# DL3056 valid-semver-labels

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct semantic version
  depends on the released artifact.

Requires labels declared as `semver` in `.rudolint.yaml` `label-schema` to
contain semantic versions.

Example config:

```yaml
label-schema:
  org.opencontainers.image.version: semver
```

Bad:

```Dockerfile
LABEL org.opencontainers.image.version="v1.2.3"
```

Good:

```Dockerfile
LABEL org.opencontainers.image.version="1.2.3"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
