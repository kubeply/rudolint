# RDK1000 buildkit-syntax-directive

- Default severity: info
- Category: buildkit
- Provenance: Rudolint BuildKit-native rule.
- Autofix: none yet.

Requires an explicit `# syntax=` directive when BuildKit-only Dockerfile
features are used.

Bad:

```Dockerfile
RUN --mount=type=cache,target=/var/cache/apt apt-get update
```

Good:

```Dockerfile
# syntax=docker/dockerfile:1
RUN --mount=type=cache,target=/var/cache/apt apt-get update
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
