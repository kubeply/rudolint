# RDL3012 single-healthcheck

- Default severity: error
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: none yet.

Allows only one `HEALTHCHECK` instruction.

Bad:

```Dockerfile
HEALTHCHECK CMD curl -f http://localhost
HEALTHCHECK CMD wget -q http://localhost
```

Good:

```Dockerfile
HEALTHCHECK CMD curl -f http://localhost
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
