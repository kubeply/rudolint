# DL3036 zypper-clean

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because shell command rewriting can change command grouping or failure behavior.

Requires zypper metadata cleanup with `zypper clean` (or its alias `zypper cc`)
in the same `RUN` layer after zypper package-manager use.

Bad:

```Dockerfile
RUN zypper install -y curl
```

Good:

```Dockerfile
RUN zypper install -y curl && zypper clean
RUN zypper install -y curl && zypper cc
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
