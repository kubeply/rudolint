# DL3006 explicit-from-tag

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct edit depends on project intent.

Requires `FROM` images to use an explicit tag or digest.

Bad:

```Dockerfile
FROM alpine
```

Good:

```Dockerfile
FROM alpine:3.20
```

Global `ARG` defaults used in `FROM` images are evaluated, including when a
variable forms part of a previous stage name:

```Dockerfile
ARG BASE=alpine:3.20
ARG STAGE=build
FROM ${BASE}

FROM alpine:3.20 AS build-base
FROM ${STAGE}-base AS final
```

The `${NAME:-fallback}`, `${NAME-fallback}`, `${NAME:+alternate}`, and
`${NAME+alternate}` forms are also evaluated when checking `FROM` images.

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
