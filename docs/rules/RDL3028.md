# RDL3028 pin-gem-versions

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct gem version depends on project intent.

Requires direct packages installed with `gem install` to use an explicit
version pin. RDL3028 accepts `gem:version` operands and `-v`/`--version`
pinning flags.

Bad:

```Dockerfile
RUN gem install bundler
```

Good:

```Dockerfile
RUN gem install bundler:2.5.11
```

```Dockerfile
RUN gem install bundler -v 2.5.11
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
