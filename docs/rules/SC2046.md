# SC2046 quote-command-substitutions

- Default severity: warning
- Category: shell
- Provenance: ShellCheck-compatible shell rule.
- Autofix: no safe automatic fix is declared because quoting can change
  intentional word splitting.

Warns when an unquoted command substitution may split into multiple shell
words.

Bad:

```Dockerfile
RUN echo $(id -u)
```

Good:

```Dockerfile
RUN echo "$(id -u)"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
