# DL3019 apk-add-no-cache

- Default severity: info
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because shell command rewriting can change command grouping or option order.

Requires `apk add` invocations to use `--no-cache` so package index data is
not persisted in the image layer.

Bad:

```Dockerfile
RUN apk add curl=8.14.1-r2
```

Good:

```Dockerfile
RUN apk add --no-cache curl=8.14.1-r2
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
