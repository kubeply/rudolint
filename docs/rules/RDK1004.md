# RDK1004 secret-mount-copied-to-layer

- Default severity: warning
- Category: buildkit
- Provenance: Rudolint BuildKit-native rule.
- Autofix: no safe automatic fix is declared because the correct remediation depends on where the build should consume the secret.

Detects `RUN --mount=type=secret` steps that copy the mounted secret file or a
file under a mounted secret directory into the image filesystem. BuildKit secret
mounts are temporary, but copying their contents makes the secret persist in the
resulting image layer.

Bad:

```Dockerfile
RUN --mount=type=secret,id=api_token cp /run/secrets/api_token /app/token
```

Good:

```Dockerfile
RUN --mount=type=secret,id=api_token deploy --token-file /run/secrets/api_token
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
