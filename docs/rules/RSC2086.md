# RSC2086 quote-variable-expansions

- Default severity: warning
- Category: shell
- Provenance: ShellCheck-compatible shell rule.
- Autofix: no safe automatic fix is declared because quoting can change
  intentional word splitting or globbing.

Warns when an unquoted variable expansion may split into multiple shell words or
expand globs.

Bad:

```Dockerfile
RUN echo $HOME
```

Good:

```Dockerfile
RUN echo "$HOME"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
