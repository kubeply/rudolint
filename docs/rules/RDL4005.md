# RDL4005 use-shell-for-default-shell

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because replacing a symlink with
  `SHELL` can affect every later `RUN` instruction.

Warns when a `RUN` instruction uses `ln` to change `/bin/sh`. Prefer the
Dockerfile `SHELL` instruction when changing the default shell.

Bad:

```Dockerfile
RUN ln -sf /bin/bash /bin/sh
```

Good:

```Dockerfile
SHELL ["/bin/bash", "-o", "pipefail", "-c"]
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
