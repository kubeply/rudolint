# RDL3024 unique-stage-names

- Default severity: error
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: none yet.

Requires unique multi-stage aliases.

Bad:

```Dockerfile
FROM alpine AS build
FROM scratch AS build
```

Good:

```Dockerfile
FROM alpine AS build
FROM scratch AS runtime
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
