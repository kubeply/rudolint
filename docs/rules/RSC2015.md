# RSC2015 command-chain-as-condition

- Default severity: warning
- Category: shell
- Provenance: ShellCheck-compatible shell rule.
- Autofix: no safe automatic fix is declared because the correct conditional
  structure depends on command intent.

Warns when `RUN` uses `A && B || C` as a conditional expression. If `B` fails,
`C` runs even when `A` succeeded.

Bad:

```Dockerfile
RUN test -d /app && cd /app || mkdir /app
```

Good:

```Dockerfile
RUN if test -d /app; then cd /app; else mkdir /app; fi
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
