# RDL3062 pin-go-versions

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because selecting a version
  requires project-specific compatibility knowledge.

Requires package references in `go install`, `go get`, and relevant `go run`
commands to include explicit versions other than `latest` or `none`. Local
paths are allowed.

Bad:

```Dockerfile
RUN go install example.com/tool/cmd/tool
```

Good:

```Dockerfile
RUN go install example.com/tool/cmd/tool@v1.2.3
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
