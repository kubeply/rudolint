# SC2164 check-cd-exit-status

- Default severity: warning
- Category: shell
- Provenance: ShellCheck-compatible shell rule.
- Autofix: no safe automatic fix is declared because the right failure handling
  depends on the build step.

Warns when `RUN cd` is not followed by an explicit `&&` or `||` check.

Bad:

```Dockerfile
RUN cd /app; make
```

Good:

```Dockerfile
RUN cd /app && make
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
