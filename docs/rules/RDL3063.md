# RDL3063 reserved-stage-name

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because renaming stages requires
  updating every related `COPY --from` reference.

Forbids stage aliases that use reserved words: `scratch` and `context`.

Bad:

```Dockerfile
FROM alpine:3.20 AS scratch
```

Good:

```Dockerfile
FROM alpine:3.20 AS build
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
