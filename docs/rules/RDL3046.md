# RDL3046 useradd-no-log-init

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because user creation flags can
  vary across distributions.

Requires `useradd` commands that set a high UID to also pass `-l` or
`--no-log-init`, avoiding large sparse `/var/log/faillog` data in the image.

Bad:

```Dockerfile
RUN useradd -u 100000 app
```

Good:

```Dockerfile
RUN useradd --no-log-init -u 100000 app
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
