# RDK1006 cache-mount-stable-id

- Default severity: info
- Category: buildkit
- Provenance: Rudolint BuildKit-native rule.
- Autofix: no safe automatic fix is declared because the cache id should reflect project and package-manager intent.

Detects `RUN --mount=type=cache` entries in multi-stage Dockerfiles that omit an
explicit `id`. Stable ids make cache reuse predictable when the same cache target
appears in different stages or when stage structure changes over time.

Bad:

```Dockerfile
FROM alpine AS deps
RUN --mount=type=cache,target=/var/cache/apk apk add build-base

FROM deps AS build
RUN --mount=type=cache,target=/root/.cache/go-build go build ./...
```

Good:

```Dockerfile
FROM alpine AS deps
RUN --mount=type=cache,id=apk-cache,target=/var/cache/apk apk add build-base

FROM deps AS build
RUN --mount=type=cache,id=go-build,target=/root/.cache/go-build go build ./...
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed:

```yaml
severity:
  RDK1006: warning

# or suppress the rule entirely:
ignore:
  - RDK1006
```
