# RDL4006 pipefail-before-pipe

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because selecting a shell depends
  on the base image and package availability.

Requires a pipefail-capable `SHELL` instruction before `RUN` commands that use
shell pipes. Non-POSIX shells such as PowerShell are treated as handling pipe
failures through their own semantics.

Bad:

```Dockerfile
RUN wget -qO- https://example.com | tar xz
```

Good:

```Dockerfile
SHELL ["/bin/bash", "-o", "pipefail", "-c"]
RUN wget -qO- https://example.com | tar xz
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
