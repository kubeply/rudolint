# DL3061 instruction-order

- Default severity: error
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because moving instructions can
  change build semantics.

Requires Dockerfiles to begin with `FROM`, `ARG`, parser directives, or
comments. Instructions such as `ENV`, `RUN`, or `COPY` before the first `FROM`
are invalid.

Bad:

```Dockerfile
ENV APP_HOME=/app
FROM alpine:3.20
```

Good:

```Dockerfile
ARG ALPINE_VERSION=3.20
FROM alpine:${ALPINE_VERSION}
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
