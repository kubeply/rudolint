# RDL4000 deprecated-maintainer

- Default severity: error
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: none yet.

Rejects deprecated `MAINTAINER` instructions.

Bad:

```Dockerfile
MAINTAINER ops@example.com
```

Good:

```Dockerfile
LABEL org.opencontainers.image.authors="ops@example.com"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
