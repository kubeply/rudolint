# DL3004 no-sudo

- Default severity: error
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct edit depends on project intent.

Rejects `sudo` inside `RUN` instructions. Docker build steps already run as the
current image user, and privilege changes should be modeled with `USER` or an
explicit privilege-drop tool.

Bad:

```Dockerfile
RUN sudo apt-get update
```

Good:

```Dockerfile
USER root
RUN apt-get update
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
