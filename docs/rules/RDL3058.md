# RDL3058 valid-email-labels

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct contact
  address depends on the image owner.

Requires labels declared as `email` in `.rudolint.yaml` `label-schema` to
contain valid email addresses.

Example config:

```yaml
label-schema:
  org.opencontainers.image.authors: email
```

Bad:

```Dockerfile
LABEL org.opencontainers.image.authors="not-an-email"
```

Good:

```Dockerfile
LABEL org.opencontainers.image.authors="team@example.com"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
