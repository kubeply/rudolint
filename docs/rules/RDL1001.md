# RDL1001 legacy-external-suppression

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint compatibility migration rule.
- Autofix: no safe automatic fix is declared because the correct edit depends on project intent.

Warns on legacy external suppression comments so projects can migrate to native
Rudolint suppressions.

Bad:

```Dockerfile
# hadolint ignore=DL3007
FROM alpine:latest
```

Good:

```Dockerfile
# rudolint ignore=RDL3007
FROM alpine:latest
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
