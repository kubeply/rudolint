# RDL3054 valid-spdx-labels

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct license
  expression depends on project licensing.

Requires labels declared as `spdx` in `.rudolint.yaml` `label-schema` to contain
valid SPDX license expressions.

Example config:

```yaml
label-schema:
  org.opencontainers.image.licenses: spdx
```

Bad:

```Dockerfile
LABEL org.opencontainers.image.licenses="Apache 2"
```

Good:

```Dockerfile
LABEL org.opencontainers.image.licenses="Apache-2.0"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
