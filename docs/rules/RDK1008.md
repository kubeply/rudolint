# RDK1008 buildkit-entitlement-opt-in

- Default severity: warning
- Category: buildkit
- Provenance: Rudolint BuildKit-native rule.
- Autofix: no safe automatic fix is declared because entitlement use needs an explicit project policy decision.

Detects BuildKit entitlements that require an explicit project opt-in through
`.rudolint.yaml` `allow-entitlements`. This rule currently covers
`RUN --network=host` (`network.host`) and `RUN --security=insecure`
(`security.insecure`).

Bad:

```Dockerfile
RUN --network=host apk add curl
RUN --security=insecure mount -t proc proc /proc
```

Good:

```Dockerfile
RUN --network=none apk add curl
RUN --security=sandbox true
```

Allowed with explicit config:

```yaml
allow-entitlements:
  - network.host
  - security.insecure
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed:

```yaml
severity:
  RDK1008: error

# or suppress the rule entirely:
ignore:
  - RDK1008
```
