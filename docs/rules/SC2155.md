# SC2155 declare-and-assign-separately

- Default severity: warning
- Category: shell
- Provenance: ShellCheck-compatible shell rule.
- Autofix: no safe automatic fix is declared because preserving scope and
  command failure behavior requires manual review.

Warns when a declaration command assigns the result of a command substitution in
the same statement, which can mask the substitution command's exit status.

Bad:

```Dockerfile
RUN export PATH="$(pwd):$PATH"
```

Good:

```Dockerfile
RUN path="$(pwd)" && export PATH="$path:$PATH"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
