# RDL3025 json-entrypoints

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: manual suggestion only until command tokenization is reliable.

Prefers exec/JSON form for `CMD` and `ENTRYPOINT`.

Bad:

```Dockerfile
CMD echo hello
```

Good:

```Dockerfile
CMD ["echo", "hello"]
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
