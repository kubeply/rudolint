# RDK1007 cache-mount-safe-sharing

- Default severity: warning
- Category: buildkit
- Provenance: Rudolint BuildKit-native rule.
- Autofix: no safe automatic fix is declared because cache sharing policy depends on the package manager and cache target.

Detects BuildKit cache mounts used with lock-based package managers such as
`apt`, `apt-get`, `dnf`, `yum`, and `microdnf` when the cache mount omits
`sharing` or explicitly uses `sharing=shared`. These package managers can use
lock files inside their cache directories, so concurrent builds should use
`sharing=locked`.

Bad:

```Dockerfile
RUN --mount=type=cache,target=/var/cache/apt apt-get update && apt-get install -y curl
RUN --mount=type=cache,target=/var/cache/dnf,sharing=shared dnf install -y git
```

Good:

```Dockerfile
RUN --mount=type=cache,target=/var/cache/apt,sharing=locked apt-get update && apt-get install -y curl
RUN --mount=type=cache,target=/var/cache/dnf,sharing=locked dnf install -y git
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed:

```yaml
severity:
  RDK1007: error

# or suppress the rule entirely:
ignore:
  - RDK1007
```
