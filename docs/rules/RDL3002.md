# RDL3002 final-user-not-root

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: none yet.

Requires the final image user to be non-root when a final `USER` instruction is
present.

Bad:

```Dockerfile
USER root
```

Good:

```Dockerfile
USER app
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
