# DL4001 either-wget-or-curl

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because replacing download tools
  changes flags, output behavior, and TLS/proxy semantics.

Warns when both `wget` and `curl` are used in the same build stage.

Bad:

```Dockerfile
RUN curl -fsSLO https://example.com/a
RUN wget https://example.com/b
```

Good:

```Dockerfile
RUN curl -fsSLO https://example.com/a
RUN curl -fsSLO https://example.com/b
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
