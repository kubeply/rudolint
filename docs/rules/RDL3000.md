# RDL3000 absolute-workdir

- Default severity: error
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: none yet.

Requires `WORKDIR` paths to be absolute so the final directory is predictable.

Bad:

```Dockerfile
WORKDIR app
```

Good:

```Dockerfile
WORKDIR /app
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
