# RDL3035 no-zypper-dist-upgrade

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct package operation depends on image and repository policy.

Avoids `zypper dist-upgrade` and its `dup` alias in Docker builds.

Bad:

```Dockerfile
RUN zypper dist-upgrade -y
```

Good:

```Dockerfile
RUN zypper install -y curl
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
