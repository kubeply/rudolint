# RDL3042 pip-no-cache-dir

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because adding `--no-cache-dir`
  can change cache behavior expected by existing builds.

Requires `pip install` invocations to avoid persisting pip cache directories.
Use `--no-cache-dir`, set `PIP_NO_CACHE_DIR` to a truthy value, or use a
BuildKit `cache` or `tmpfs` mount for `.cache/pip`.

Bad:

```Dockerfile
RUN pip install flask
```

Good:

```Dockerfile
RUN pip install --no-cache-dir flask
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
