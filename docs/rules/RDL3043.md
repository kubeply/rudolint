# RDL3043 no-onbuild-trigger

- Default severity: error
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because nested trigger
  instructions require human intent.

Rejects `ONBUILD` instructions that trigger `ONBUILD`, `FROM`, or
`MAINTAINER`.

Bad:

```Dockerfile
ONBUILD FROM alpine:3.20
```

Good:

```Dockerfile
ONBUILD RUN echo ok
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
