# DL3057 missing-healthcheck

- Default severity: ignore
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct health command
  depends on the containerized service.

Requires each image stage to define or inherit a `HEALTHCHECK` instruction.
This rule is disabled by default; enable it by setting a non-`ignore` severity
in `.rudolint.yaml`.

Example config:

```yaml
severity:
  DL3057: warning
```

Bad:

```Dockerfile
FROM alpine:3.20
```

Good:

```Dockerfile
FROM alpine:3.20
HEALTHCHECK CMD wget -qO- http://localhost/health || exit 1
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
