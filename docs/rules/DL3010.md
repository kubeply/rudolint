# DL3010 use-add-for-archives

- Default severity: info
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because archive extraction intent must be confirmed.

Prefers `ADD` when a local archive source should be extracted into the image.

Bad:

```Dockerfile
COPY rootfs.tar.gz /
```

Good:

```Dockerfile
ADD rootfs.tar.gz /
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
