# DL3023 copy-from-own-stage

- Default severity: error
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct source stage depends on build intent.

Forbids `COPY --from` from referencing the stage that contains the `COPY`
instruction. DL3023 catches both alias self-references and numeric
`COPY --from=<current stage index>` self-references.

Bad:

```Dockerfile
FROM alpine:3.20 AS runtime
COPY --from=runtime /app /app
```

```Dockerfile
FROM alpine:3.20 AS runtime
COPY --from=0 /app /app
```

Good:

```Dockerfile
FROM alpine:3.20 AS build
RUN mkdir -p /out && touch /out/app

FROM alpine:3.20 AS runtime
COPY --from=build /out/app /app
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
