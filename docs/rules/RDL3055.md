# RDL3055 valid-git-hash-labels

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct git revision
  depends on the built source.

Requires labels declared as `git-hash` in `.rudolint.yaml` `label-schema` to
contain lowercase hexadecimal git hashes of length 7 or 40.

Example config:

```yaml
label-schema:
  org.opencontainers.image.revision: git-hash
```

Bad:

```Dockerfile
LABEL org.opencontainers.image.revision="ABC1234"
```

Good:

```Dockerfile
LABEL org.opencontainers.image.revision="abcdef1"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
