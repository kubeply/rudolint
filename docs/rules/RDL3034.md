# RDL3034 zypper-install-assume-yes

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because shell command rewriting can change command grouping or option order.

Requires `zypper install` invocations to include `-y`, `-n`, or
`--non-interactive` so Docker builds do not stop for prompts.

Bad:

```Dockerfile
RUN zypper install curl
```

Good:

```Dockerfile
RUN zypper install -y curl
```

```Dockerfile
RUN zypper --non-interactive install curl
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
