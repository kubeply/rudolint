# RUD1001 legacy-external-suppression

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint compatibility migration rule.
- Autofix: no safe automatic fix is declared on the rule because migration is
  opt-in; use `rudolint check . --fix --migrate-hadolint-ignores` to convert
  legacy Hadolint inline suppressions to native Rudolint suppressions.

Warns on legacy external suppression comments so projects can migrate to native
Rudolint suppressions.

Bad:

```Dockerfile
# hadolint ignore=DL3007
FROM alpine:latest
```

Good:

```Dockerfile
# rudolint ignore=DL3007
FROM alpine:latest
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
