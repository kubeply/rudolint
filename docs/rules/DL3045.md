# DL3045 copy-relative-without-workdir

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct destination
  path depends on image layout intent.

Requires `COPY` destinations to be absolute unless a `WORKDIR` has been set in
the current stage.

Windows drive-absolute destinations such as `C:\app` and `C:/app` are treated as
absolute. Relative Windows destinations such as `.\app` or `pkg-resolver` still
trigger the rule when no `WORKDIR` has been set.

Bad:

```Dockerfile
COPY app.py app/
```

Good:

```Dockerfile
WORKDIR /app
COPY app.py .
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
