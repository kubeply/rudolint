# RSC2181 check-exit-code-directly

- Default severity: warning
- Category: shell
- Provenance: ShellCheck-compatible shell rule.
- Autofix: no safe automatic fix is declared because restructuring the command
  chain may change control flow.

Detects tests of `$?`. Check the command directly with `&&`, `||`, or an `if`
condition so the relationship between the command and its error handling stays
clear.

Bad:

```Dockerfile
RUN make; test $? -eq 0
```

Good:

```Dockerfile
RUN make && echo ok
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
