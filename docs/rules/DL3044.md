# DL3044 no-env-self-reference

- Default severity: error
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because splitting or reordering
  `ENV` statements can change intended image metadata.

Rejects references to an environment variable within the same `ENV` statement
where that variable is first defined.

Bad:

```Dockerfile
ENV PATH="$APP_HOME/bin:$PATH" APP_HOME=/app
```

Good:

```Dockerfile
ENV APP_HOME=/app
ENV PATH="$APP_HOME/bin:$PATH"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
