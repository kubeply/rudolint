# RDL3050 no-superfluous-labels

- Default severity: info
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because removing labels can
  remove image metadata relied on by downstream systems.

When `.rudolint.yaml` `strict-labels` is enabled, rejects `LABEL` keys that are
not declared in `label-schema`.

Example config:

```yaml
strict-labels: true
label-schema:
  org.opencontainers.image.title: text
```

Bad:

```Dockerfile
LABEL org.opencontainers.image.title="rudolint" extra.label="value"
```

Good:

```Dockerfile
LABEL org.opencontainers.image.title="rudolint"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
