# RDL3001 disallowed-container-commands

- Default severity: info
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct edit depends on project intent.

Warns when `RUN` instructions invoke interactive or system-management commands
that rarely make sense during Docker builds, including `ssh`, `vim`, `shutdown`,
`service`, `ps`, `free`, `top`, `kill`, `mount`, and `ifconfig`.

Bad:

```Dockerfile
RUN service nginx start
```

Good:

```Dockerfile
RUN nginx -t
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
