# DL3041 pin-dnf-versions

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct package
  version depends on project intent.

Requires direct packages installed with `dnf install` to use explicit version
pins.

Bad:

```Dockerfile
RUN dnf install -y curl
```

Good:

```Dockerfile
RUN dnf install -y curl-8.6.0
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
