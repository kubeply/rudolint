# RDL3053 valid-rfc3339-labels

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct timestamp
  depends on project metadata.

Requires labels declared as `rfc3339` in `.rudolint.yaml` `label-schema` to
contain RFC3339 timestamp values.

Example config:

```yaml
label-schema:
  org.opencontainers.image.created: rfc3339
```

Bad:

```Dockerfile
LABEL org.opencontainers.image.created="2026-05-16"
```

Good:

```Dockerfile
LABEL org.opencontainers.image.created="2026-05-16T12:30:00Z"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
