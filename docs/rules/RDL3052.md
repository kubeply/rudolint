# RDL3052 valid-url-labels

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct URL depends
  on project metadata.

Requires labels declared as `url` in `.rudolint.yaml` `label-schema` to contain
valid URL values.

Example config:

```yaml
label-schema:
  org.opencontainers.image.source: url
```

Bad:

```Dockerfile
LABEL org.opencontainers.image.source="not a url"
```

Good:

```Dockerfile
LABEL org.opencontainers.image.source="https://github.com/kubeply/rudolint"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
