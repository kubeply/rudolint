# RDL3013 pin-pip-versions

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct package version depends on project intent.

Requires direct packages installed with `pip install` or `pip3 install` to use
an exact `==` version pin.

Bad:

```Dockerfile
RUN pip install flask
```

Good:

```Dockerfile
RUN pip install flask==3.0.0
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
