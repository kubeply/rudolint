# DL3015 apt-get-no-install-recommends

- Default severity: info
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because package installation options should be reviewed together.

Requires `apt-get install` commands to use `--no-install-recommends` so images
avoid pulling unnecessary recommended packages.

Bad:

```Dockerfile
RUN apt-get install -y curl
```

Good:

```Dockerfile
RUN apt-get install -y --no-install-recommends curl
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
