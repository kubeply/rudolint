# DL3040 dnf-clean-all

- Default severity: info
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because shell command rewriting can change command grouping or failure behavior.

Requires `dnf install` invocations to clean package metadata with
`dnf clean all` in the same `RUN` layer.

Bad:

```Dockerfile
RUN dnf install -y curl
```

Good:

```Dockerfile
RUN dnf install -y curl && dnf clean all
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
