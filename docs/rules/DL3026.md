# DL3026 trusted-registries

- Default severity: error
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct trusted registry and image mirror depend on project policy.

When `.rudolint.yaml` declares `trusted-registries`, requires `FROM` images to
come from one of those registries. The rule is inactive when no trusted
registries are configured.

Bad:

```Dockerfile
# .rudolint.yaml: trusted-registries: [ghcr.io]
FROM docker.io/library/alpine:3.20
```

Good:

```Dockerfile
# .rudolint.yaml: trusted-registries: [ghcr.io]
FROM ghcr.io/example/alpine:3.20
```

Configure with `.rudolint.yaml` `trusted-registries`, `ignore`, or `severity`
entries when needed.
