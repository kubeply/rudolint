# RDK1002 secret-in-run

- Default severity: warning
- Category: buildkit
- Provenance: Rudolint BuildKit-native rule.
- Autofix: none yet.

Flags `RUN` instructions that appear to pass secret values without a BuildKit
secret mount.

Bad:

```Dockerfile
RUN TOKEN=abc deploy
```

Good:

```Dockerfile
RUN --mount=type=secret,id=token deploy
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
