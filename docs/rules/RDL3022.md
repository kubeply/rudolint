# RDL3022 copy-from-previous-stage

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because the correct stage alias or external image reference depends on build intent.

Requires `COPY --from` references to resolve to a previous build stage alias
or numeric stage index. External image references that include a tag are
accepted.

Bad:

```Dockerfile
FROM alpine:3.20
COPY --from=build /out/app /app
```

Good:

```Dockerfile
FROM alpine:3.20 AS build
RUN mkdir -p /out && touch /out/app

FROM alpine:3.20
COPY --from=build /out/app /app
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
