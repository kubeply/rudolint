# RDL3027 use-apt-get

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because `apt` subcommands do not always map one-to-one to `apt-get` or `apt-cache`.

Prefers `apt-get` or `apt-cache` over `apt`, which is intended for interactive
end-user use rather than stable scripts.

Bad:

```Dockerfile
RUN apt install curl
```

Good:

```Dockerfile
RUN apt-get install curl
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
