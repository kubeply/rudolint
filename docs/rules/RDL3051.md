# RDL3051 no-empty-labels

- Default severity: warning
- Category: compatibility
- Provenance: Hadolint-compatible Dockerfile rule.
- Autofix: no safe automatic fix is declared because missing metadata values
  depend on the project.

Requires labels declared in `.rudolint.yaml` `label-schema` to have non-empty
values when present.

Example config:

```yaml
label-schema:
  org.opencontainers.image.title: text
```

Bad:

```Dockerfile
LABEL org.opencontainers.image.title=""
```

Good:

```Dockerfile
LABEL org.opencontainers.image.title="rudolint"
```

Configure with `.rudolint.yaml` `ignore` or `severity` entries when needed.
